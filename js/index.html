🧱 C'est quoi un bloc { } ?

Un bloc c'est tout ce qui se trouve entre une accolade ouvrante { et une accolade fermante }. C'est comme une pièce fermée : ce qui est créé à l'intérieur reste à l'intérieur.

DEHORS if (score > 10) { ← accolade ouvrante = début du bloc
DEDANS let message = "Gagné !"; ↑ cette variable n'existe QUE dans ce bloc
} ← accolade fermante = fin du bloc · message n'existe plus ici
💡
Règle simple : une variable let ou const ne vit que dans le bloc { } où elle est née. En dehors, elle est invisible. On appelle ça la portée (scope en anglais).

Exemple concret

let score = 15; // ← DEHORS : visible partout if (score > 10) { // Début du bloc let bonus = 5; // ← DEDANS : existe seulement ici console.log(score); // ✅ OK (score est dehors) console.log(bonus); // ✅ OK (bonus est dedans) } // Fin du bloc → bonus disparaît console.log(score); // ✅ OK console.log(bonus); // ❌ ERREUR : bonus n'existe plus !

🔠 Valeur, type, chaîne… le vocabulaire de base

Avant de coder, il faut connaître ces mots. On les utilise tout le temps.

Valeur Ce qu'on met dans une variable — le contenu réel
Dans let score = 10, la valeur c'est 10.
Dans let nom = "Noah", la valeur c'est "Noah".
La valeur peut être un nombre, du texte, vrai/faux, une liste…
String Chaîne de caractères — du texte
Une suite de lettres, chiffres, espaces, symboles… toujours entre guillemets.
"Bonjour"  ·  'Hello'  ·  "1100 messages"  ·  "a"
⚠️ "42" est une String (texte), pas un nombre — on ne peut pas faire de calcul avec.
Number Nombre — entier ou décimal
Sans guillemets. On peut faire des calculs avec.
42  ·  3.14  ·  1100  ·  -5
Boolean Booléen — seulement deux valeurs possibles : vrai ou faux
true (vrai)  ou  false (faux). Jamais de guillemets, jamais de nombre.
C'est le résultat de toute comparaison : 1100 > 1000 → true
Array Tableau — une liste ordonnée de valeurs
Entre crochets [ ], séparées par des virgules. Chaque case a un numéro qui commence à 0.
["pomme", "banane", "cerise"] → 3 éléments, indices 0, 1, 2
Object Objet — des données regroupées avec des étiquettes
Entre accolades { }. Chaque donnée a un nom (clé) et une valeur.
{ nom: "Noah", age: 13, actif: true }
💡
Résumé facile : le type dit quelle sorte de donnée c'est (texte ? nombre ? vrai/faux ?). La valeur c'est le contenu réel. JS se comporte différemment selon le type — c'est pourquoi 42 + 1 donne 43 mais "42" + 1 donne "421" (collage de texte).

✏️ Template Literals — écrire du texte avec des variables

❌ Ancienne façon
let msg = "Bonjour " + prenom + " !";
✅ Nouvelle façon (backticks)
let msg = `Bonjour ${prenom} !`;
💡
Les backticks `...` permettent d'insérer des variables avec ${variable}. Tu peux aussi calculer : ${2 + 2} affiche 4.

🔀 Structure if / else if / else

if (condition1) { // Bloc 1 — exécuté si condition1 est vraie } else if (condition2) { // Bloc 2 — exécuté si condition2 est vraie } else { // Bloc 3 — exécuté si aucune condition n'est vraie }
📌
JS lit de haut en bas. Dès qu'une condition est vraie, il exécute ce bloc et ignore tous les autres.

🧱 Les blocs { } dans un if

Chaque if, else if et else a son propre bloc. JS n'entre dans un bloc que si la condition est vraie :

if (note >= 16) {← entre ici SEULEMENT si note ≥ 16
console.log("Très bien !");
} else if (note >= 10) {← entre ici si note ≥ 10 (et < 16)
console.log("Reçu");
} else {← entre ici si aucun des blocs précédents n'a été vrai
console.log("Échoué");
}

⚡ Opérateur ternaire — if en une ligne

// condition ? valeur_si_vrai : valeur_si_faux let age = 17; let acces = age >= 18 ? "Autorisé" : "Interdit"; console.log(acces); // "Interdit"

🔀 switch / case

let jour = "Lundi"; switch (jour) { case "Lundi": console.log("Début de semaine"); break; // ← OBLIGATOIRE pour stopper case "Samedi": case "Dimanche": console.log("Week-end !"); break; default: console.log("Jour ordinaire"); }
⚠️
Sans break, JS continue sur le case suivant ! C'est le bug classique du switch.

🔁 La boucle for — Quand on sait combien de fois

// for (départ ; condition ; étape) for (let i = 0; i < 5; i++) { console.log(`Tour n°${i}`); } // Affiche : Tour n°0, n°1, n°2, n°3, n°4
let i = 0
départ Le compteur démarre à 0. S'exécute une seule fois au début.
i < 5
condition Vérifiée avant chaque tour. Dès que faux → la boucle s'arrête.
i++
étape Après chaque tour, on ajoute 1 au compteur.

🔁 La boucle while

let energie = 100; while (energie > 0) { console.log(`Énergie : ${energie}`); energie -= 30; } // Affiche 100, 70, 40, 10
🚨
Si tu oublies de faire avancer la condition dans un while, la boucle tourne à l'infini et bloque le navigateur !

📋 for...of — Parcourir un tableau

const fruits = ["pomme", "banane", "cerise"]; for (const fruit of fruits) { console.log(fruit); } // pomme, banane, cerise
✅
for...of est la façon moderne de parcourir un tableau. Plus simple que le for classique.

🛠️ break et continue

break — Stopper la boucle

for (let i = 0; i < 10; i++) { if (i === 5) break; console.log(i); } // 0, 1, 2, 3, 4

continue — Sauter un tour

for (let i = 0; i < 6; i++) { if (i % 2 === 0) continue; console.log(i); } // 1, 3, 5 (impairs)

🔄 Portée (scope) — Où existe une variable ?

let global = "Visible partout"; function maFonction() { let local = "Visible seulement ici"; console.log(global); // ✅ OK console.log(local); // ✅ OK } console.log(global); // ✅ OK console.log(local); // ❌ ERREUR : local n'existe pas ici
📌
C'est la même règle que les blocs { } : une variable let ou const dans une fonction n'existe qu'à l'intérieur de cette fonction.

🌐 C'est quoi le DOM ?

Le DOM (Document Object Model) est la représentation de ta page HTML sous forme d'objets JavaScript. Grâce à lui, JS peut lire et modifier le contenu, le style et la structure de ta page en temps réel.

// La page HTML = un arbre : // html → body → div → p → "Du texte" // JS peut attraper n'importe quelle branche et la modifier
