🧱 C'est quoi un bloc { } ?

Un bloc c'est tout ce qui se trouve entre une accolade ouvrante { et une accolade fermante }. C'est comme une pièce fermée : ce qui est créé à l'intérieur reste à l'intérieur.

DEHORS if (score > 10) { ← accolade ouvrante = début du bloc
DEDANS let message = "Gagné !"; ↑ cette variable n'existe QUE dans ce bloc
} ← accolade fermante = fin du bloc · message n'existe plus ici
💡
Règle simple : une variable let ou const ne vit que dans le bloc { } où elle est née. En dehors, elle est invisible. On appelle ça la portée (scope en anglais).

Exemple concret

let score = 15; // ← DEHORS : visible partout if (score > 10) { // Début du bloc let bonus = 5; // ← DEDANS : existe seulement ici console.log(score); // ✅ OK (score est dehors) console.log(bonus); // ✅ OK (bonus est dedans) } // Fin du bloc → bonus disparaît console.log(score); // ✅ OK console.log(bonus); // ❌ ERREUR : bonus n'existe plus !

🔠 Valeur, type, chaîne… le vocabulaire de base

Avant de coder, il faut connaître ces mots. On les utilise tout le temps.

Valeur Ce qu'on met dans une variable — le contenu réel
Dans let score = 10, la valeur c'est 10.
Dans let nom = "Noah", la valeur c'est "Noah".
La valeur peut être un nombre, du texte, vrai/faux, une liste…
String Chaîne de caractères — du texte
Une suite de lettres, chiffres, espaces, symboles… toujours entre guillemets.
"Bonjour"  ·  'Hello'  ·  "1100 messages"  ·  "a"
⚠️ "42" est une String (texte), pas un nombre — on ne peut pas faire de calcul avec.
Number Nombre — entier ou décimal
Sans guillemets. On peut faire des calculs avec.
42  ·  3.14  ·  1100  ·  -5
Boolean Booléen — seulement deux valeurs possibles : vrai ou faux
true (vrai)  ou  false (faux). Jamais de guillemets, jamais de nombre.
C'est le résultat de toute comparaison : 1100 > 1000 → true
Array Tableau — une liste ordonnée de valeurs
Entre crochets [ ], séparées par des virgules. Chaque case a un numéro qui commence à 0.
["pomme", "banane", "cerise"] → 3 éléments, indices 0, 1, 2
Object Objet — des données regroupées avec des étiquettes
Entre accolades { }. Chaque donnée a un nom (clé) et une valeur.
{ nom: "Noah", age: 13, actif: true }
💡
Résumé facile : le type dit quelle sorte de donnée c'est (texte ? nombre ? vrai/faux ?). La valeur c'est le contenu réel. JS se comporte différemment selon le type — c'est pourquoi 42 + 1 donne 43 mais "42" + 1 donne "421" (collage de texte).

🔀 Structure if / else if / else

🧱 Les blocs { } dans un if

Chaque if, else if et else a son propre bloc. JS n'entre dans un bloc que si la condition est vraie :

console.log("Très bien !");
} else if (note >= 10) {← entre ici si note ≥ 10 (et < 16)
console.log("Reçu");
} else {← entre ici si aucun des blocs précédents n'a été vrai
console.log("Échoué");
}

📐 Sur quoi brancher l'événement ?

unElement.addEventListener(...)
Réagit uniquement quand l'action se passe sur cet élément précis.
Ex : un bouton, une div, un input
document.addEventListener(...)
Réagit quand l'action se passe n'importe où dans la page.
Ex : keydown, keypress — peu importe où l'utilisateur est
window.addEventListener(...)
Réagit sur des événements globaux de la fenêtre.
Ex : scroll, mousemove, load, resize

🖱️ Souris — click

Se déclenche une fois par clic (enfoncer + relâcher).

btn.addEventListener("click", () => { // action au clic }); // Avec la position du clic : body.addEventListener("click", (e) => { console.log(e.pageX, e.pageY); // position du clic console.log(e.target); // élément précisément cliqué });
💡
e.pageX et e.pageY existent aussi bien dans "click" que dans "mousemove".

🖱️ Souris — mousemove

Se déclenche en continu à chaque pixel que la souris parcourt. Utilise-le pour suivre la souris en temps réel.

window.addEventListener("mousemove", (e) => { // Déplacer un élément avec la souris : curseur.style.left = e.pageX + "px"; curseur.style.top = e.pageY + "px"; // Modifier une variable CSS : nav.style.setProperty("--x", e.layerX + "px"); nav.style.setProperty("--y", e.layerY + "px"); });
⚠️
Ne jamais créer d'élément dans "mousemove" — ça créerait des milliers d'éléments par seconde. Pour créer à la position de la souris, utilise "click".

🖱️ Souris — mousedown / mouseup

"mousedown" = bouton enfoncé · "mouseup" = bouton relâché.

window.addEventListener("mousedown", () => { el.style.transform = "scale(2) translate(-25%, -25%)"; }); window.addEventListener("mouseup", () => { el.style.transform = "scale(1) translate(-50%, -50%)"; el.style.border = "2px solid teal"; });

🖱️ Souris — mouseenter / mouseout / mouseover

Les trois réagissent quand la souris entre ou sort d'un élément. La différence est subtile.

// mouseenter : souris ENTRE dans l'élément (ne se propage pas aux enfants) div.addEventListener("mouseenter", () => { div.style.background = "rgba(0,0,0,0.6)"; }); // mouseout : souris SORT de l'élément OU d'un de ses enfants div.addEventListener("mouseout", () => { div.style.background = "pink"; }); // mouseover : souris passe AU-DESSUS (se propage aux enfants) p.addEventListener("mouseover", () => { p.style.transform = "rotate(2deg)"; });
ÉvénementSe déclenche quand…Enfants inclus ?
"mouseenter"La souris entre dans l'élément❌ Non
"mouseleave"La souris sort de l'élément❌ Non
"mouseover"La souris passe au-dessus✅ Oui
"mouseout"La souris sort✅ Oui
💡
En pratique : utilise "mouseenter" + "mouseleave" dans la plupart des cas — ils ne se déclenchent pas sur les éléments enfants, ce qui évite les comportements inattendus.

🎯 click vs mousemove — ne pas confondre

mousemove — suivi en continu
window.addEventListener("mousemove", (e) => { // Des milliers de fois par seconde // → suivre la position, effets visuels });
click — une seule fois par clic

⚠️

🧠 La méthode universelle en 4 étapes

Cette méthode sépare ce que l'app sait (les données) de ce que l'utilisateur voit (l'affichage). Le JS ne regarde jamais l'écran — il regarde ses variables.

1. SÉLECTIONS Attraper les éléments
const element = document.querySelector(".maClasse");
Toujours en const — ces références ne changent jamais.
2. DONNÉES L'état de l'app
let maDonnee = ""; // ou 0, ou false
En let car ces valeurs vont changer. C'est la mémoire de l'application.
3. AFFICHAGE updateDisplay
const updateDisplay = () => { element.propriété = maDonnee; };
Règle : element_html.propriété = variable_étape_2
Se place avant les événements. Ne décide de rien, obéit à l'état.
4. ÉVÉNEMENT Le déclencheur
element.addEventListener("evenement", (e) => { maDonnee = e.propriété_événement; updateDisplay(); });
Règle : variable_étape_2 = e.propriété_événement
On ne touche jamais au CSS directement ici.
💡
updateDisplay n'est pas un mot-clé JS — tu peux l'appeler comme tu veux. Pour un simple body.classList.toggle("dark"), tu peux mettre l'action directement dans l'événement sans passer par une fonction.

🔁 Variante — forEach (plusieurs éléments)

Quand tu veux le même comportement sur plusieurs éléments. La grande différence : pas de variable étape 2 — chaque élément porte son propre état via sa classe CSS.

C'est quoi forEach ?

forEach est une boucle. Une boucle = répéter la même action plusieurs fois. Sans forEach, pour 4 items tu écrirais :

❌ Sans forEach — répétitif
items[0].addEventListener("click", ...) items[1].addEventListener("click", ...) items[2].addEventListener("click", ...) items[3].addEventListener("click", ...)
✅ Avec forEach — automatique
items.forEach((item) => { item.addEventListener("click", ...) })
💡
Traduction en français : "Pour chaque item de ma liste, ajoute un écouteur de clic."
forEach fait exactement la même chose que les 4 lignes du dessus, mais automatiquement — peu importe combien d'items il y a.
1. SÉLECTIONS
const elements = document.querySelectorAll(".classeSelectionnee");
querySelectorAll retourne une liste de tous les éléments correspondants.
2. DONNÉES
Pas de variable globale — chaque élément porte son propre état via sa classe CSS.
3. AFFICHAGE
const updateDisplay = (element) => { element.classList.toggle("nomDeLaClasseCSS"); };
La fonction reçoit l'élément en paramètre — elle agit sur celui qui a été cliqué, pas sur tous.
4. ÉVÉNEMENT
elements.forEach((element) => { element.addEventListener("click", () => { updateDisplay(element); }); });
forEach parcourt chaque élément et lui branche son propre addEventListener.

⚡ Le circuit fermé — Ce qui va dans l'étape 3 vs l'étape 4

C'est ici que la majorité des erreurs se produisent. La règle est simple mais stricte.

❌ Erreur classique — CSS dans l'étape 4
body.addEventListener("click", (e) => { // ❌ On touche au style ICI → mauvais maBrique.style.left = e.pageX + "px"; // ❌ maBrique n'existe pas encore ici ! updateDisplay(); });

Crash garanti : maBrique est créé dans l'étape 3, pas encore dans l'étape 4.

✅ Correct — L'étape 4 stocke, l'étape 3 affiche
body.addEventListener("click", (e) => { // ✅ On stocke juste les valeurs brutes posX = e.pageX; posY = e.pageY; // ✅ On délègue l'affichage à l'étape 3 updateDisplay(); });

L'étape 4 ne sait pas comment afficher — elle confie les données à updateDisplay.

La règle à retenir

Étape 4 — Événement
Je récupère les données brutes de l'action : e.pageX, e.key, e.target.value...
Je les stocke dans mes variables (posX = e.pageX).
Je ne touche jamais au style ici.
Étape 3 — updateDisplay
Je lis les variables de l'étape 2.
Je crée ou modifie les éléments HTML.
J'applique le style et le + "px".
Tout ce qui touche à l'affichage est ici.
⚠️
Piège fréquent : tu vois e.pageX dans un exemple avec mousemove dans ton cours. Mais e.pageX existe aussi dans un click. Ce n'est pas l'outil qui change — c'est l'événement qui le déclenche.

📏 Les règles d'or

Règle 1 — Texte = guillemets, variable = jamais de guillemets

❌ Piège classique
h3.textContent = "count"; // Affiche le MOT "count" // pas la valeur de la variable !
✅ Correct
h3.textContent = count; // Affiche la VALEUR // stockée dans count

Règle 2 — Modifier la donnée D'ABORD, afficher ensuite

❌ Affiche l'ancienne valeur
updateDisplay(); // ← trop tôt count++; // trop tard
✅ Bon ordre
count++; // 1. donnée updateDisplay(); // 2. affichage

Règle 3 — Tu te répètes ? C'est le signal d'une fonction

❌ Code dupliqué = fragile
plus.addEventListener("click", () => { count++; h3.textContent = count; // répété h3.style.color = "green"; // répété }); moins.addEventListener("click", () => { count--; h3.textContent = count; // répété h3.style.color = "red"; // répété });
✅ Fonction = 1 endroit à modifier
const maj = () => { h3.textContent = count; h3.style.color = count > 0 ? "green" : count < 0 ? "red" : "grey"; }; plus.addEventListener("click", () => { count++; maj(); }); moins.addEventListener("click", () => { count--; maj(); });

Règle 4 — L'ordre dans le fichier

// 1. Récupérer les éléments HTML const btn = document.querySelector("#btn");
En premier, toujours. On ne peut pas utiliser ce qu'on n'a pas encore récupéré.
// 2. Déclarer les variables de données let score = 0;
Les variables qui stockent l'état de l'appli (score, choix, liste en cours...).
// 3. Déclarer les fonctions const maj = () => { /* ... */ };
Les fonctions qu'on appellera depuis les événements.
// 4. Brancher les événements btn.addEventListener("click", () => { maj(); });
En dernier. On branche les interactions une fois que tout le reste est prêt.

Règle 5 — querySelector utilise la syntaxe CSS

document.querySelector("#monId") // id → # document.querySelector(".maClasse") // classe → . document.querySelector("h3") // balise → nom seul document.querySelector(".card button") // imbriqué → comme en CSS
⚠️
querySelector renvoie le premier élément trouvé. Pour tous les récupérer, utilise querySelectorAll — qui renvoie une liste sur laquelle tu peux faire un forEach.

🏗️ Créer du HTML en JS — Deux méthodes

Quand tu veux ajouter un élément dans la page depuis JS, tu as deux approches. Les deux fonctionnent, mais pas dans les mêmes situations.

École 1 — innerHTML (dans ton cours)
document.body.innerHTML += ` <div class='box'> <h2>Nouvelle Boite !</h2> </div> `;

Tu écris du HTML sous forme de texte. Le navigateur le lit et l'injecte.
Avantage : facile à écrire, ressemble à du HTML normal.
Limite : le navigateur recharge tout le bloc à chaque fois.

École 2 — createElement (méthode propre)
const div = document.createElement("div"); div.style.background = "red"; div.style.width = "50px"; document.body.appendChild(div);

JS fabrique une vraie balise en mémoire, tu lui appliques des propriétés, puis tu l'insères.
Avantage : plus rapide pour la machine, propre, contrôle total.
Quand l'utiliser : éléments dynamiques, cercles, cartes générées à la volée.

Le schéma mental de createElement

const el = document.createElement("div");
1. Fabriquer JS crée une <div> en mémoire. Elle n'est pas encore dans la page — elle n'existe que dans la variable el.
el.style.color = "red"; el.textContent = "Salut";
2. Configurer Tu lui appliques tout ce que tu veux — style, texte, classes, événements — avant de l'insérer.
document.body.appendChild(el);
3. Insérer Seulement là, l'élément apparaît dans la page. appendChild l'ajoute à la fin du parent choisi.
💡
Pour des projets simples, innerHTML suffit amplement. Utilise createElement quand tu génères beaucoup d'éléments à la volée ou quand tu veux attacher des événements à chaque élément créé.

🎯 Je veux attraper un élément HTML

document.querySelector("#monId") document.querySelector(".maClasse") document.querySelector("h3")
méthode étape 1 Retourne le premier élément qui correspond au sélecteur CSS.
# pour un id · . pour une classe · nom seul pour une balise

méthode étape 1 Retourne tous les éléments correspondants. Utilise .forEach() pour les parcourir un par un.
document.getElementById("monId")
méthode étape 1 Variante ancienne — cible un élément par son id sans le #. Même résultat que querySelector("#monId").

✏️ Je veux changer le texte ou le HTML affiché

el.textContent = maVariable el.textContent = "du texte"
propriété étape 3 Remplace le texte brut de l'élément.
❌ el.textContent = "count" → affiche le mot
✅ el.textContent = count → affiche la valeur

propriété étape 3 Injecte du HTML à l'intérieur de l'élément. Le += ajoute sans effacer le contenu existant.

🎨 Je veux changer le style CSS

propriété étape 3 Modifie un style CSS en ligne. La valeur est toujours une string entre guillemets.

propriété étape 3 Pour les dimensions et positions : le nombre vient d'une variable (sans guillemets) et on lui colle l'unité "px" avec +.

propriété étape 3 Les propriétés CSS composées (avec tiret) s'écrivent en camelCase en JS : border-radius → borderRadius, font-size → fontSize.

méthode étape 3 Modifie une variable CSS custom (--x, --couleur...). Plus puissant que style.color car ça peut affecter tous les enfants qui utilisent cette variable.

🏷️ Je veux ajouter / retirer / basculer une classe CSS

📦 Ce que contient l'objet e

Quand tu ajoutes (e) dans ta fonction fléchée, JS te passe automatiquement toutes les infos sur l'action qui vient de se produire.

e.target
propriété étape 4 L'élément précisément sur lequel l'action s'est passée.
e.target.remove() → supprime l'élément cliqué
e.target.value
propriété étape 4 Texte tapé dans un <input> ou valeur d'un <select>. Utilisé avec les événements "input" et "change".
e.key
propriété étape 4 La touche pressée : "a", "Enter", "ArrowLeft"... Utilisé avec "keydown" et "keypress".
e.pageX / e.pageY
propriété étape 4 Position de la souris en pixels depuis le coin haut-gauche de la page. Utilisé avec "click" et "mousemove".
e.layerX / e.layerY
propriété étape 4 Position de la souris dans l'élément parent. Utilisé pour setProperty avec des variables CSS.
e.preventDefault()
méthode étape 4 Bloque le comportement par défaut du navigateur. Indispensable sur "submit" pour éviter que la page se recharge.
e.stopPropagation()
méthode Empêche l'événement de "remonter" vers les éléments parents. Si tu cliques sur un enfant, le parent ne reçoit pas le clic.

🏗️ Je veux créer ou supprimer un élément HTML

const el = document.createElement("div")
méthode étape 3 Crée une balise HTML en mémoire — pas encore visible. Il faut ensuite la configurer et l'insérer avec appendChild.
parent.appendChild(el)
méthode étape 3 Insère el à la fin de parent. C'est seulement là que l'élément apparaît dans la page.
el.remove() e.target.remove()
méthode Supprime l'élément de la page. e.target.remove() supprime précisément l'élément sur lequel on a cliqué.

⏱️ Je veux déclencher quelque chose dans le temps

setTimeout(() => { ... }, 2000)
méthode Exécute la fonction une seule fois après le délai en millisecondes (2000 = 2 secondes).
const id = setInterval(() => { ... }, 1000) clearInterval(id)
méthode Exécute la fonction en boucle toutes les X ms. Stocker le résultat dans une variable permet de l'arrêter avec clearInterval.

🪟 Je veux interagir avec la fenêtre et le navigateur

alert("Message") confirm("Supprimer ?") prompt("Ton nom ?")
méthode Dialogues natifs du navigateur. confirm retourne true/false, prompt retourne le texte saisi.

propriété Infos sur la fenêtre. scrollY = pixels scrollés depuis le haut. innerHeight = hauteur visible de la fenêtre.
location.href location.host location.pathname location.replace("url")
propriété/méthode Infos sur l'URL actuelle. replace() redirige vers une autre page.
navigator.userAgent
propriété Retourne une chaîne décrivant le navigateur et l'OS de l'utilisateur.

méthode Navigation dans l'historique du navigateur. back() = page précédente, go(-2) = deux pages en arrière.

🔢 Je veux récupérer la valeur d'un champ

propriété étape 4 Texte tapé dans un <input type="text"> ou valeur d'un <input type="range">. Toujours une string — utilise parseInt() si tu as besoin d'un nombre.
