🎨 Comment CSS fonctionne

h1 { /* sélecteur — qui on cible */ color: red; /* propriété : valeur */ font-size: 24px; /* taille en pixels */ background-color: #fff; /* couleur de fond */ }
💡
Chaque règle CSS = un sélecteur + des propriétés entre accolades. La propriété et la valeur sont séparées par : et chaque ligne se termine par ;.

🌈 Les couleurs en CSS

/* Nom de couleur */ color: red; color: cornflowerblue; /* Hexadécimal — le plus courant */ color: #e34c26; /* rouge orangé */ color: #fff; /* blanc (raccourci) */ color: #000; /* noir */ /* RGB — rouge, vert, bleu (0 à 255) */ color: rgb(227, 76, 38); /* RGBA — avec transparence (0 à 1) */ color: rgba(227, 76, 38, 0.5); /* HSL — teinte, saturation, luminosité */ color: hsl(14, 75%, 52%);

⚙️ Variables CSS (Custom Properties)

✅
Les variables CSS te permettent de changer une couleur ou une taille en un seul endroit pour tout le site. C'est indispensable sur un vrai projet !

📦 Le modèle de boîte (Box Model)

Chaque élément HTML est une boîte avec 4 couches :

margin — espace EXTÉRIEUR
border — la bordure
padding — espace INTÉRIEUR
CONTENU
.boite { margin: 20px; /* espace extérieur (autour de la boîte) */ border: 2px solid #333; /* bordure visible */ padding: 16px; /* espace intérieur (entre bordure et contenu) */ width: 300px; /* largeur du contenu */ }

🔧 box-sizing: border-box

❌ Par défaut (content-box)

width: 300px; padding: 20px; /* Largeur réelle = 340px !! */ /* 300 + 20 + 20 */

✅ Recommandé (border-box)

box-sizing: border-box; width: 300px; padding: 20px; /* Largeur réelle = 300px ✅ */
/* À mettre au tout début de TOUT projet */ *, *::before, *::after { box-sizing: border-box; }

↔️ Flexbox — La mise en page flexible

Flexbox organise les éléments sur un axe (horizontal ou vertical). Il y a deux acteurs :

📦 Le conteneur
L'élément sur lequel on met display: flex. Il contrôle comment ses enfants sont organisés.
🧩 Les items
Les enfants directs du conteneur. Ils répondent aux règles flexbox du parent.
.conteneur { display: flex; /* ← active flexbox sur les enfants */ }

📐 Les valeurs de position

ValeurComportementQuand l'utiliser

⚠️
Règle fondamentale : un élément absolute se positionne par rapport à son ancêtre relative le plus proche. Si aucun ancêtre n'est relative, il se positionne par rapport à la page entière.

🔧 top / right / bottom / left / z-index

.parent { position: relative; /* crée le contexte */ } .enfant { position: absolute; top: 14px; /* 14px depuis le haut du parent */ right: 20px; /* 20px depuis la droite du parent */ } .par-dessus { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); /* centrage parfait */ z-index: 10; /* par-dessus les autres éléments */ }
💡
top: 50%; left: 50%; transform: translate(-50%, -50%) est la recette universelle pour centrer un élément en position absolue.

🔄 transition — Animer un changement de style

transition anime le passage d'un style à un autre (au hover, au focus, quand une classe change).

button { background: pink; transition: 0.3s; /* toutes les propriétés en 0.3s */ } button:hover { background: red; /* ← animé automatiquement */ letter-spacing: 3px; } /* Cibler une propriété précise */ .card { transition: transform 0.2s ease; } /* Plusieurs propriétés */ .card { transition: background 0.3s, transform 0.2s; }

🔀 transform — Déplacer, redimensionner, faire pivoter

/* Déplacer */ .el { transform: translateX(50px); } /* → droite */ .el { transform: translateY(-20px); } /* ↑ haut */ .el { transform: translate(-50%, -50%); } /* centrage absolu */ /* Redimensionner */ .el { transform: scale(1.2); } /* 20% plus grand */ .el { transform: scale(0.5); } /* moitié */ .el { transform: scaleX(0); } /* largeur = 0 (pour les lignes) */ /* Faire pivoter */ .el { transform: rotate(45deg); } /* 45° dans le sens horaire */ .el { transform: rotate(344deg); } /* Combiner plusieurs transforms */ .el { transform: translateX(-50%) scaleX(0); } /* Point d'origine de la transformation */ .el { transform-origin: center; } /* défaut */ .el { transform-origin: left; } /* depuis la gauche */ /* 3D — nécessite perspective sur le parent */ .parent { perspective: 30px; } .el { transform: translateZ(30px); } /* vers l'avant */

🎬 animation + @keyframes

Contrairement à transition qui réagit à un changement, animation se joue automatiquement.

/* 1. Définir l'animation avec @keyframes */ @keyframes monAnimation { 0% { transform: translateX(-50%) scaleX(0); } 100% { transform: translateX(-50%) scaleX(1); } } /* 2. Appliquer sur un élément */ .el { animation: monAnimation 6s ease-in-out forwards; } /* ↑ nom durée timing mode-remplissage */ /* Animation en boucle infinie */ .spaceship { animation: voler 60s infinite linear; } /* Avec étapes intermédiaires */ @keyframes rebond { 0% { transform: scale(1); } 50% { transform: scale(1.2); } 100% { transform: scale(1); } }
Mode remplissageEffet
forwardsReste sur le dernier état après la fin
backwardsCommence sur le premier état avant de jouer
bothCombine forwards et backwards
infiniteSe répète indéfiniment (à la place d'un nombre)

✨ filter — Effets visuels sur un élément

/* Ombre portée (sur l'élément, respecte la transparence) */ .logo { filter: drop-shadow(-1px 6px 3px pink); } /* drop-shadow(x y flou couleur) */ /* Luminosité */ .el:hover { filter: brightness(120%); } /* plus lumineux */ .el { filter: brightness(50%); } /* plus sombre */ /* Flou */ .floue { filter: blur(4px); } /* backdrop-filter — flou sur le fond DERRIÈRE l'élément */ .glass { background: rgba(0, 0, 0, 0.5); backdrop-filter: blur(5px); /* effet verre dépoli */ }
💡
box-shadow et drop-shadow ne font pas la même chose : box-shadow suit le rectangle de la boîte, drop-shadow suit la forme réelle de l'élément (utile pour les PNG avec transparence).

🔲 CSS Grid — La mise en page en 2D

Grid organise les éléments sur deux axes (colonnes ET lignes). Parfait pour les mises en page complexes.

.conteneur { display: grid; grid-template-columns: 30% 70%; /* 2 colonnes */ grid-template-columns: 1fr 1fr 1fr; /* 3 colonnes égales */ grid-template-columns: repeat(3, 1fr); /* idem, version courte */ grid-template-rows: 1fr 1fr 1fr; /* 3 lignes */ gap: 16px; /* espace entre les cases */ }
💡
fr = fraction de l'espace disponible. 1fr 2fr = la 2e colonne est deux fois plus large que la 1ère.

🗺️ grid-template-areas — Nommer les zones

Permet de dessiner visuellement la mise en page avec des noms.

form { display: grid; grid-template-columns: 1fr 1fr; grid-template-rows: 1fr 1fr 1fr; grid-template-areas: "i1 i2" /* ligne 1 : deux inputs côte à côte */ "ta ta" /* ligne 2 : textarea sur toute la largeur */ "vi bt"; /* ligne 3 : vide + bouton */ } /* Assigner chaque élément à sa zone */ textarea { grid-area: ta; } #btn-submit { grid-area: bt; }
💡
Un . dans grid-template-areas représente une cellule vide.
