🏗️ Structure de base d'une page HTML

<!-- Tape ! puis Tab dans VS Code pour générer ça automatiquement --> <!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Titre de la page</title> <link rel="stylesheet" href="style.css"> </head> <body> <!-- Le contenu visible de ta page --> <h1>Mon premier titre</h1> <p>Un paragraphe de texte.</p> <script src="script.js"></script> </body> </html>
💡
<head> contient les informations invisibles (titre de l'onglet, liens CSS, métadonnées).
<body> contient tout le contenu visible de la page.

🧱 Les balises — Comment ça marche ?

Une balise HTML est comme une boîte qui entoure du contenu pour lui donner un sens.

ANATOMIE D'UNE BALISE
<p class="intro">Mon texte ici</p>
↑ balise ouvrante     ↑ attribut     ↑ contenu     ↑ balise fermante

Balises auto-fermantes (pas de balise fermante)

<img src="photo.jpg" alt="Description"> <br> <!-- Retour à la ligne --> <hr> <!-- Ligne horizontale --> <input type="text"> <meta charset="UTF-8">

📦 Balises de conteneur (div & span)

<div> — Bloc

<div class="container"> <p>Paragraphe 1</p> <p>Paragraphe 2</p> </div>

Prend toute la largeur. Commence sur une nouvelle ligne.

<span> — Inline

<p>Du texte avec un <span class="rouge">mot rouge</span> au milieu.</p>

Reste sur la même ligne. Entoure juste une partie du texte.

📋 Le <head> — Informations invisibles de la page

Le <head> contient toutes les métadonnées : titre, liens CSS/JS, favicon, encodage, etc. Rien dans le <head> ne s'affiche directement sur la page.

<head> <!-- Encodage des caractères (toujours en premier !) --> <meta charset="UTF-8"> <!-- Responsive design (mobile) --> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Titre de la page (affiché dans l'onglet) --> <title>Mon super site</title> <!-- Description pour Google --> <meta name="description" content="Description du site"> <!-- Favicon (icône dans l'onglet) --> <link rel="icon" type="image/png" href="favicon.png"> <!-- Lien vers la feuille de style CSS --> <link rel="stylesheet" href="style.css"> <!-- Script JavaScript (mieux à la fin du body) --> <script src="script.js" defer></script> </head>

🖼️ Le Favicon — Icône dans l'onglet du navigateur

Le favicon est la petite icône qui s'affiche dans l'onglet du navigateur, à côté du titre.

Format recommandé

<!-- PNG ou ICO, taille 32×32 ou 64×64 pixels --> <link rel="icon" type="image/png" href="favicon.png"> <!-- Ou fichier .ico --> <link rel="icon" type="image/x-icon" href="favicon.ico">
💡
Si ton favicon s'appelle favicon.ico et qu'il est à la racine de ton site, pas besoin de balise <link> : les navigateurs le trouvent automatiquement !

📂 Chemins de fichiers — Comment trouver un fichier ?

Quand tu fais référence à un fichier (CSS, JS, image...), tu dois indiquer son chemin (où il se trouve).

Structure d'exemple

ARBORESCENCE DE DOSSIERS
📁 mon-site/
├── 📄 index.html
├── 📁 css/
│ └── 📄 style.css
├── 📁 js/
│ └── 📄 script.js
├── 📁 images/
│ ├── 📄 logo.png
│ └── 📄 favicon.ico
└── 📁 pages/
└── 📄 contact.html

Les 3 types de chemins

TypeSyntaxeExempleQuand l'utiliser
Relatif simplefichier.extstyle.cssLe fichier est dans le même dossier
Sous-dossierdossier/fichier.extcss/style.cssLe fichier est dans un dossier enfant
Dossier parent../fichier.ext../images/logo.pngRemonter d'un niveau dans l'arborescence
Absolu/dossier/fichier.ext/css/style.cssDepuis la racine du site (serveur)

Exemples concrets depuis index.html

<!-- Fichier dans le même dossier --> <link href="style.css"> <!-- Fichier dans un sous-dossier --> <link href="css/style.css"> <img src="images/logo.png"> <!-- Lien vers une autre page HTML --> <a href="pages/contact.html">Contact</a>

Exemples depuis pages/contact.html (sous-dossier)

<!-- Remonter d'un niveau avec ../ --> <link href="../css/style.css"> <img src="../images/logo.png"> <a href="../index.html">Retour accueil</a>
⚠️
Règle d'or :
• ./ = dossier actuel (optionnel, ./style.css = style.css)
• ../ = dossier parent (remonter d'un niveau)
• ../../ = remonter de deux niveaux
• / au début = racine du site (serveur uniquement, ne fonctionne pas en local)

🔗 Liens CSS et JavaScript

Importer un fichier CSS

<!-- Dans le head --> <link rel="stylesheet" href="css/style.css"> <!-- CSS externe (Google Fonts, Bootstrap...) --> <link rel="stylesheet" href="https://fonts.googleapis.com/...">

Importer un fichier JavaScript

<!-- Méthode 1 : dans le head avec defer --> <script src="js/script.js" defer></script> <!-- Méthode 2 : à la fin du body (avant </body>) --> <script src="js/script.js"></script>
💡
defer vs à la fin du body :
• defer = le script se charge en parallèle et s'exécute après le chargement du HTML
• À la fin du <body> = le HTML charge d'abord, puis le script (méthode classique)

📮 Structure d'un formulaire

<form action="/traitement.php" method="POST"> <!-- Champ texte --> <label for="nom">Nom :</label> <input type="text" id="nom" name="nom" required> <!-- Bouton d'envoi --> <button type="submit">Envoyer</button> </form>
💡
action = où envoyer les données
method = comment les envoyer (GET ou POST)
Chaque <input> doit avoir un attribut name pour que les données soient envoyées.

🔑 id, name, placeholder — trois attributs, trois rôles

Ces trois attributs se ressemblent mais font des choses complètement différentes.

AttributRôleExemple concret
id Identifiant unique dans la page. Sert à cibler l'élément en JS avec querySelector("#monId") et à lier un <label> via for="monId".
⚠️ Deux éléments ne peuvent pas avoir le même id.		 id="password-field"
name Clé envoyée au serveur lors du submit du formulaire. Sans name, le champ est ignoré. Peut être différent de id. name="password"
placeholder Texte indicatif qui disparaît dès que tu tapes. Purement cosmétique — jamais envoyé au serveur, pas une valeur par défaut. placeholder="Entrez votre mot de passe..."

Exemple complet — label + input avec tous les attributs

<!-- Le for du label doit correspondre exactement à l'id de l'input --> <label for="password-field">Mot de passe :</label> <input type="password" id="password-field" name="password" placeholder="Entrez votre mot de passe..." required >
⚠️
Cliquer sur le texte du <label> active directement l'input — mais seulement si for et id ont exactement la même valeur.

🎯 HTML Sémantique — Donner du sens à la structure

Au lieu d'utiliser des <div> partout, utilise des balises qui décrivent le contenu. C'est meilleur pour le SEO, l'accessibilité et la lisibilité du code.

STRUCTURE SÉMANTIQUE TYPE
<header> <nav>Menu de navigation</nav> </header> <main> <article> <h1>Titre de l'article</h1> <section> <h2>Première partie</h2> <p>Contenu...</p> </section> </article> <aside> Barre latérale / Pub </aside> </main> <footer> Pied de page </footer>

🗺️ Guide de décision — Quelle balise utiliser dans <main> ?

Pose-toi ces questions dans l'ordre pour choisir la bonne balise :

📄
QUESTION 1
Le contenu peut-il être autonome ?
(Indépendant, partageable seul)
✅ OUI → Utilise <article>
Exemples : Article de blog, fiche produit, carte d'événement, commentaire, post sur réseau social
❌ NON → Passe à la question suivante
📑
QUESTION 2
Est-ce un regroupement thématique clair ?
(Avec son propre titre H2/H3)
✅ OUI → Utilise <section>
Exemples : Chapitre d'un article, section "Caractéristiques" d'un produit, partie thématique d'une page
⚠️ RÈGLE : Une <section> a TOUJOURS un titre (h2, h3...)
❌ NON → Passe à la question suivante
📌
QUESTION 3
Est-ce un contenu tangentiel / connexe ?
(Lien indirect avec le sujet principal)
✅ OUI → Utilise <aside>
Exemples : Barre latérale, bio d'auteur, liens connexes, publicités, "Le saviez-vous ?", widget météo
❌ NON → Passe à la question suivante
📦
QUESTION 4
Est-ce uniquement pour la mise en page / le style ?
(Pas de sens sémantique)
✅ OUI → Utilise <div>
Exemples : Conteneur générique, grille CSS, wrapper de mise en page, emballage pour flexbox/grid
💡 Le <div> n'a AUCUN sens sémantique. C'est une boîte vide pour organiser visuellement.
👇 Si rien ne correspond, reconsidère les balises sémantiques ci-dessus
🎯
En résumé :
<article> = contenu autonome (article, produit, post)
<section> = regroupement thématique avec titre
<aside> = contenu périphérique (sidebar, bio, liens)
<div> = conteneur générique sans sens (pure mise en page)

BaliseUsage

<nav>Zone de navigation (menu principal)
<main>Contenu principal de la page (un seul par page !)
<article>Contenu autonome (article de blog, carte produit...)
<section>Section thématique (chapitre, partie d'article...)

✅ Sémantique

<header> <nav>...</nav> </header> <main> <article>...</article> </main> <footer>...</footer>
